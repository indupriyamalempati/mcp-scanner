# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this scanner, please report it
privately by emailing:

**imalempa@umd.edu**

Do NOT open a public GitHub issue for security vulnerabilities.

Please include:
- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You can expect an initial response within 72 hours.

## Scope

This scanner is designed for authorized security testing only.
Do not run it against MCP servers you do not own or have permission to test.
